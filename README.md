# cally — JoseloFarias fork

Grabador de llamadas Android basado en Shizuku, mantenido por **JoseloFarias** para investigación, pruebas y mejora de grabación no-root en dispositivos compatibles.

## Objetivos

- Mejorar compatibilidad y estabilidad de captura de ambas partes de la llamada.
- Mantener una arquitectura simple, auditable y sin telemetría innecesaria.
- Validar comportamiento real en dispositivos antes de declarar soporte.
- Conservar atribuciones, licencias y referencias al proyecto original.

## Estado

Proyecto experimental/en validación. La compatibilidad depende del dispositivo, versión de Android, implementación de audio y permisos disponibles mediante Shizuku.

## Desarrollo

```bash
git clone https://github.com/joselofarias-byte/cally.git
cd cally
./gradlew assembleDebug
```

## Uso responsable

La grabación de llamadas está sujeta a la legislación aplicable en cada jurisdicción.
